Tôi đang tham gia cuộc thi "VIBE CODE CHALLENGE - TỰ TAY LÀM RA SẢN PHẨM, ĐƯA LÊN VIBE HOST".

Hãy viết cho tôi TRỌN GÓI toàn bộ mã nguồn của một ứng dụng Web trong ĐÚNG MỘT FILE HTML duy nhất (bao gồm cả HTML structure, CSS styling trong thẻ <style>, và JavaScript logic trong thẻ <script>).

 

Yêu cầu chi tiết về sản phẩm:

 

1. TÊN ỨNG DỤNG:

- "Flashcard Vibe (Spaced Repetition App)"

 

2. TÍNH NĂNG CỐT LÕI & CHỨC NĂNG:

- Thuật toán Spaced Repetition (SM-2 giản lược): Mỗi thẻ Flashcard sau khi xem mặt sau sẽ có 3 nút đánh giá mức độ ghi nhớ:

  + "Chưa nhớ" (Ôn lại sau 1 phút)

  + "Bình thường" (Ôn lại sau 1 ngày)

  + "Rất nhớ" (Ôn lại sau 3 ngày)

- Phát âm AI (Text-to-Speech): Dùng Web Speech API (`window.speechSynthesis`) native của trình duyệt. Thêm một biểu tượng cái loa 🔊 trên thẻ, bấm vào để đọc chuẩn tiếng Anh (en-US) mà không cần dùng bất kỳ thư viện ngoài nào.

- Dữ liệu lưu trữ local: Sử dụng LocalStorage để lưu trạng thái tiến độ học, số thẻ đã thuộc và lịch hẹn ôn tập (nhằm giữ dữ liệu khi F5 trình duyệt).

- Dữ liệu mẫu (Data JSON): Tích hợp sẵn khoảng 5-6 thẻ từ vựng mẫu chủ đề IT/Công sở (gồm: Term, Phonetic, Definition, Example, Image URL từ Unsplash).

 

3. YÊU CẦU THIẾT KẾ (UI/UX):

- Phong cách giao diện: Hiện đại, hiện đại chuẩn SaaS (Dark Mode hoặc Light Mode sạch sẽ, bo tròn góc, có bóng đổ mượt).

- Trải nghiệm Flashcard: Thẻ bài có hiệu ứng lật mặt (Flip animation) mượt mà khi người dùng click vào thẻ.

- Dashboard mini ở đầu trang: Hiển thị thống kê nhanh: "Tổng số thẻ", "Số thẻ cần ôn hôm nay", "Số thẻ đã thuộc".

- Responsive: Hiển thị đẹp mắt trên cả điện thoại di động và máy tính.

 

4. ĐẦU RA MÃ NGUỒN (OUTPUT CRITERIA):

- Trả về mã nguồn HOÀN CHỈNH trong 1 khối code duy nhất.

- Không viết code dạng rút gọn, không dùng ghi chú kiểu "// viết code tại đây".

- File HTML này có thể lưu thành `index.html`, mở trực tiếp trên trình duyệt là chạy ngay 100% không lỗi.
